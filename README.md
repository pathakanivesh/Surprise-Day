# Birthday Surprise
A special interactive birthday surprise website created .

##  Features

-  3D Flipping Birthday Card
-  Personalized Typewriter Message (Hindi + English)
- Interactive "Reasons Why You're Amazing" Cards
- Grand Finale with Fireworks & Confetti
-  Rainbow Animated Text
-  Fully Responsive

##  Technologies Used

- React.js
- React Router DOM
- Framer Motion
- React Confetti
- CSS3 Animations

## How to Run

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173`
